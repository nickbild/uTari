# µTari

µTari is an Atari 2600, only smaller. 

An original 2600 PCB measures about 9.75 x 5.25 inches. The µTari PCB is 4.7 x 3.5 inches. All of the original chips (6507 CPU, TIA, RIOT) were used in making the µTari — it's the real deal, not an emulator or FPGA.
